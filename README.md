# 🛒 Sistema PDV (Ponto de Venda) em Delphi

Projeto de Conclusão de Curso (PDV) desenvolvido em **Delphi** com foco em automação comercial, emissão de vendas e integração com banco de dados e API de CEP. Desenvolvido como parte do aprendizado prático em arquitetura de software desktop e banco de dados.

## 🚀 Tecnologias e Ferramentas
* **Linguagem:** Object Pascal (Delphi)
* **Framework / Componentes:** VCL, FireDAC
* **Banco de Dados:** PostgreSQL / Firebird
* **Arquitetura:** Padrão de camadas (DataModule, Regras de Negócio, Interface)

## 📌 Funcionalidades Principais
* Tela de Vendas (PDV) ágil e intuitiva para operador de caixa.
* Controle e consulta de cadastro de Clientes e Produtos.
* Gerenciamento de Estoque em tempo real.
* Conexão segura e otimizada via FireDAC.
